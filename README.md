## 📌 Sobre o projeto

O Conserta Tudo é um sistema desenvolvido em Java para o gerenciamento de serviços de manutenção residencial.

O projeto foi desenvolvido como atividade acadêmica, com o objetivo de aplicar conceitos de Programação Orientada a Objetos (POO).

## ⚙️ Tecnologias utilizadas

- Java 17
- Programação Orientada a Objetos (POO)
- Arquivos CSV para armazenamento de dados
- Testes automatizados

## 📋 Requisitos para execução

Para executar o projeto, é necessário:

- Windows 10 ou superior.
- Java JDK 17 ou superior instalado.
- Prompt de Comando (CMD) ou PowerShell.

**Importante:** É necessário ter o JDK instalado, pois o projeto utiliza o compilador `javac`.

Download do Java: https://adoptium.net/temurin/releases/

## ▶️ Como executar o projeto

1. Baixe ou clone este repositório.
2. Extraia os arquivos do projeto.
3. Abra a pasta principal do projeto.
4. Execute o arquivo `executar.bat`.

O arquivo realiza a compilação e inicia o sistema.

### Executar pelo terminal

```cmd
executar.bat
```

## 🧪 Como executar os testes

```cmd
executar.bat testes
```

## 🚀 Funcionalidades

- Cadastro de clientes.
- Cadastro de técnicos.
- Gerenciamento de serviços.
- Gerenciamento de ordens de serviço.
- Atendimento de emergências.
- Cobrança de taxas adicionais para emergências.
- Programa de fidelidade.
- Descontos e pontos para clientes.
- Registro de pagamentos.
- Geração de relatórios.
- Armazenamento de informações em arquivos CSV.

## 💾 Armazenamento de dados

O sistema utiliza arquivos CSV para armazenar as informações cadastradas.

A pasta `dados/` guarda os registros do sistema. Não exclua essa pasta durante a utilização.

## 🎓 Finalidade acadêmica

Projeto desenvolvido para aplicar conhecimentos de Java e Programação Orientada a Objetos na criação de um sistema de gerenciamento de serviços de manutenção residencial.
